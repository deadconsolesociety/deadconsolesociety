# Dead Console Society


**New life for dead consoles.**


Dead Console Society documents independent **PSP homebrew**, **PS Vita ports**, early **NES experiments** and retro-console development with honest, evidence-backed progress updates.


## Current projects


- **Elite: Next PSP** — playable PSP development project with spaceflight, planetary exploration and ERL racing.
- **Brutal Doom Vita** — PS Vita launcher, porting and multiplayer testing.
- **Talisman PSP** — playable PSP development work with ongoing rules, visuals and testing.
- **Marble Blast Ultra Vita Port** — active Vita porting work; no public download is currently offered.
- **Might & Magic NES → Skyrim experiment** — very early research into first-person towns and movement; unfinished graphics and no release announced.
